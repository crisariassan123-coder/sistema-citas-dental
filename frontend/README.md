# Frontend – Sistema de Citas Dental

Interfaz web para que los pacientes agenden su cita. Hecha con React + Vite.

## Requisitos
- Node.js (LTS)
- El backend corriendo en `http://localhost:8080`

## Cómo ejecutarlo
```bash
npm install
npm run dev
```
`http://localhost:5173`. Las peticiones a `/api` se reenvían al backend mediante el proxy configurado en `vite.config.js`.
